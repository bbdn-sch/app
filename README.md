## 📱 Tentang Sedabatu App

Sedabatu App dikembangkan secara mandiri oleh Tim IT SDN Babadan 01 sebagai jembatan komunikasi digital terpadu antara pihak sekolah dengan wali murid. Seluruh transmisi data terhubung langsung ke server mandiri sekolah secara aman, terenkripsi, bebas iklan komersial, dan 100% gratis.

### ✨ Fitur Utama Aplikasi

1. **Presensi Gerbang Sekolah Real-Time (IoT RFID)**
   - Notifikasi kehadiran otomatis masuk ke smartphone wali murid secara instan saat kartu murid ditap pada terminal gerbang sekolah (checkpoint masuk & pulang).
   - Rekapitulasi persentase kehadiran bulanan, ketepatan waktu, izin, dan sakit.

2. **e-Rapor Kurikulum Merdeka SD**
   - Akses transparan nilai capaian pembelajaran (Fase A, B, dan C) per mata pelajaran.
   - Portofolio penilaian formatif, sumatif, dan deskripsi capaian kompetensi murid secara berkala.

3. **Buku Ketertiban & Komunikasi Sekolah**
   - Pemantauan catatan kedisiplinan dan poin tata tertib murid secara real-time.
   - Saluran pengumuman resmi agenda akademik, kalender pendidikan, dan kegiatan sekolah.

## 📥 Cara Mengunduh & Memasang

### Opsi A: Melalui Portal Web Resmi (Direkomendasikan)
Kunjungi portal unduhan resmi di **[get.babadan.sch.id](https://get.babadan.sch.id)** dari browser ponsel Android Anda, pilih varian yang sesuai, lalu tekan tombol **"Unduh APK"**.

### Opsi B: Langsung dari Repositori GitHub Ini
1. Buka tab **[Releases](https://github.com/bbdn-sch/app/releases)** di repositori ini.
2. Cari rilis dengan label **Latest**.
3. Pada bagian **Assets**, ketuk berkas `Sedabatu.apk` (atau `Sedabatu-legacy.apk` untuk perangkat lama) untuk mengunduh biner instalasi.

## ⚙️ Petunjuk Pemasangan di Ponsel Android

Karena Sedabatu App didistribusikan secara mandiri oleh server lokal sekolah:

1. **Unduh Berkas:** Jika muncul peringatan browser *"File mungkin berbahaya"*, pilih **"Tetap unduh"** (prosedur keamanan standar Android untuk berkas APK di luar Play Store).
2. **Izin Sumber Aplikasi:** Buka berkas `.apk` yang selesai diunduh. Jika muncul dialog perizinan sistem, masuk ke **Setelan** dan aktifkan opsi **"Izinkan dari sumber ini"**.
3. **Selesaikan Instalasi:** Ketuk tombol **"Pasang"** atau **"Instal"**, lalu buka aplikasi dan masuk menggunakan akun resmi dari sekolah.
